2. SYSTEM COMPONENT DETAILS
------------------------------------------------------------------------

======================================
A. THE BACKEND SYSTEM (Spring Boot)
======================================
The backend is structured under `src/main/java/fr/plus33/api` following standard
enterprise-tier Clean Architecture patterns:

1. CONFIGURATION LAYER (`/config`)
   - SecurityConfig.java: Sets up security protocols, configures CORS exceptions
     for client-side domains, and manages public vs. authenticated API permissions.
   - WebMvcConfig.java: Registers global MVC behaviors, CORS mappings, and static
     resource pathways.

2. CONTROLLER LAYER (`/controller`)
   Exposes REST endpoints consuming and producing JSON.
   - AiRecommendationController.java: Recommends products using similarity metrics.
   - AnimationController.java: Dynamically serves visual configuration settings.
   - CategoryController.java: Category CRUD interface.
   - MediaController.java: Facilitates secure file transfers to Cloudinary.
   - NavController.java: Handles layout and menu hierarchies.
   - ProductController.java: Product CRUD, filters, and paginated searches.

3. DTO LAYER (`/dto`)
   Decouples internal database schemas from the public-facing API.
   - ApiResponse.java: Envelopes all REST responses in a standardized format.
   - CategoryDto.java: Serialized category representation.
   - ProductDto.java: Clean product response package including CDN image URLs.

4. DATABASE MODEL LAYER (`/model`)
   Standard JPA Entities mapped to SQL tables.
   - Animation.java: Stores parameters for custom homepage motion effects.
   - Category.java: Repositories map these categories to products.
   - MediaUpload.java: Tracks Cloudinary resource descriptors and secure URLs.
   - Product.java: Standard catalog item parameters, plus AI tags and embeddings.
   - UserActivity.java: Audits user events to train future recommendation engines.

5. REPOSITORY LAYER (`/repository`)
   Abstracts database queries by utilizing Spring Data JPA interfaces.
   - All repositories inherit `JpaRepository<Entity, ID>` for automatic transactional CRUD.

6. SERVICE LAYER (`/service`)
   Coordinates business transactions and business rules.
   - AiRecommendationService.java: Evaluates product recommendation weights.
   - AnimationService.java: Business rules for cinematic configs.
   - CategoryService.java: Category data management.
   - MediaService.java: Integrates Cloudinary API, uploading buffers to the cloud.
   - ProductService.java: Powers product searches, pagination, sorting, and tag filters.

7. APPLICATION ENTRYPOINT
   - Plus33ApiApplication.java: Holds the `@SpringBootApplication` entry point.

======================================
B. CONFIGURATION & INFRASTRUCTURE
======================================
- application.properties: Manages variables for the server port (8083), database 
  connection strings, JPA settings, upload limits, and Cloudinary API credentials.
- pom.xml: Controls the Maven build cycle, managing dependencies like Spring Boot,
  Lombok, Spring Security, Cloudinary SDK, and database connectors.
- compose.yaml: Deploys backing containers like local databases (MySQL) seamlessly.

======================================
C. THE FRONTEND SYSTEM (SPA Client)
======================================
The frontend is a lightweight Single Page Application served out of the 
`/resources/static` directory, designed for fast load times and premium animations.

1. ROUTING & CLIENT ARCHITECTURE (`/js`)
   - index.html: Acts as the base shell. Navbars, footers, and page views are 
     injected here dynamically depending on user actions.
   - router.js: Client-side routing engine. Maps routes (e.g., `/`, `/store`) to 
     corresponding HTML templates and triggers view-specific logic.
   - app.js: Entry point for the frontend, booting the router and layout engines.

2. VIEWS AND STYLING (`/html` & `/css`)
   - home.html & home.css: Standard landing view designed with a luxury, cinematic 
     layout, animated with scroll-driven effects.
   - store.html & store.css: Renders the premium coffee catalog with dynamic filtering, 
     responsive grids, and aesthetic transitions.

3. SHARED RESOURCES & SUBPAGES (`/global`)
   - layout-engine.js: Assembles shared components (navbar.html, footer.html) 
     into active views.
   - chatbot.js & chatbot.css: Interactive chat interface driven by chatbot-data.js.
   - find-us.html & find-us.js: Coordinates store locators.
   - franchise.html & franchise.js: Handles information structures for franchise signups.
   - journal.html & journal.js: High-end blog layout representing brand lifestyle.
